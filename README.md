# Ficha de Ingreso - páginas web

Páginas del sistema de recepción de autos para taller. Las carga el proyecto de Google Apps Script
(`UrlFetchApp` desde este repo), así que no contiene claves, datos de clientes ni configuración privada.

- `apps/index.html`: ficha de ingreso
- `apps/taller.html`: tablero Kanban del taller
- `apps/ver.html`: vista del cliente
- `apps/branding.html`: datos del taller (nombre, teléfono, logo)
